Badges

Badge (atoms 1.1.1) — 20px pill, 8px x-padding, 12px / 500, 4px gap, 12px icons. Semantic variants default · secondary · destructive · outline · ghost · link plus a Tailwind color system (gray, blue, purple, amber, red, pink, green, teal), each solid or -subtle. Since #480 default is brand green and link is green text (text-primary), not the blue --link.
