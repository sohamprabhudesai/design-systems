Buttons

Button — variants default · outline · secondary · ghost · destructive · destructive-soft · link; sizes xs 24px · sm 28px · default 32px · lg 36px (+ icon squares). 14px medium, radius 10px (8px for xs/sm). The default button is near-black, not colored — color is reserved for destructive and status.

Dark mode

In dark mode the default button inverts (near-white bg, dark text); outline gets a subtle input/30 fill. Pair one default button with ghost/outline neighbors — never two filled CTAs side by side.
