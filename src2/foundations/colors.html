Color Tokens

neeto-atoms uses semantic OKLCH tokens (shadcn convention) — never raw hex in designs. The primary action color is near-black (--primary: oklch(0.205 0 0)), inverting to near-white in dark mode. Every token has a light and dark value; components reference tokens only, so dark mode is automatic.

successbg · border · fgsuccess-solid

warningbg · border · fgwarning-solid

Each status has 5 tokens: --{status} (soft bg), --{status}-border, --{status}-foreground (text on soft bg), --{status}-solid and --{status}-solid-foreground (filled chips/toasts).
