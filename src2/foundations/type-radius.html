Radius — --radius: 0.625rem (10px), derived steps

sm · 6px — Kbd, Badge rounded is 4px
md · 8px — xs/sm buttons, menu items, tab trigger, tooltip, toast
lg · 10px — buttons, inputs, Callout, Menu, Popover
xl · 14px — Card, Dialog, Alert, Empty
pill — Badge, Switch, Avatar, Progress
--radius-sm = radius − 4, -md = radius − 2, -lg = radius, -xl = radius + 4. Sheets are square; Checkbox is 4px.
