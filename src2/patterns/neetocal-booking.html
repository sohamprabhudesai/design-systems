The remap works for everything that reads --primary / --secondary / --background / --foreground / --border / --link, and neetoCal's [data-slot=alert] patch (mirrored here) keeps callout text readable and derives the info palette from the theme. Two findings remain: (1) the scope sets --primary, not --brand, so any atoms part that reads --brand / --brand-text (the brand button, sidebar selection) would stay neeto-green on a themed page. (2) only info is derived. warning / success / error (and the subtle badges) keep atoms light-mode pastels, so on a dark-card theme like "Night" they render as light boxes. They stay readable but are off-theme. The fix is to derive all four status sets the way info already is.
