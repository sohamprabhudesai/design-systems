Corrected since the previous catalog

  • Search is a debounced search input, not a ⌘K palette — ⌘K is FinderModal.
  • CardLayout is a centered form card with a sticky muted footer; Columns is a column-visibility dropdown. Neither is a grid scaffold.
  • Onboarding is a full-page stepper flow, not a checklist.
  • Insights is form analytics with no charts and no chart tokens.
  • Sidebar is 240px (resizable); product switcher and profile live in FloatingActionMenu.
  • SubHeader has no built-in counts or badges; Header owns the 32px title, breadcrumbs, HelpPopover and Search.
  • ErrorPage covers 404/403/429/500; PageLoader is an arc, not a ring.
  • Added: Builder, DownloadMobileAppCallout, Engagements, MenuBar, ProductEmbed, ResponsiveDevicePicker, Schedule, ShareRecordingPane, StickyRibbon, TableWrapper, Taxonomy, TimeFormat.
  • Storybook URL removed — not verifiable from the published package.
