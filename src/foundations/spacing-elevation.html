Radius, Elevation & Layout

Spacing follows a 4px grid (0.25rem increments; 8/12/16/24px are the most common gaps). Default control radius is 5px (--neeto-ui-rounded); transitions are all 0.3s linear.

Border radius

none · 0
sm · 3px — checkboxes
default · 5px — buttons, inputs
md · 6px — callouts, toasts
lg · 8px — cards
xl · 12px — modals
full · 999px — tags, avatars, pills

Elevation

shadow-xs
xs — subtle lift (cards)
shadow-sm
sm — raised elements
shadow-md
md — pane footer, sticky bars
shadow-lg
lg — dropdowns, popovers

Focus ring

3px solid rgba(primary-500, 50%), offset 1px
border primary-500 + 3px 15% halo
