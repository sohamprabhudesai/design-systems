Buttons

Component: Button — props style (primary · secondary · tertiary · text · link · danger · danger-text), size (small 28px · medium 32px · large 40px), icon, iconPosition, loading, disabled, fullWidth. Font is 14px medium (16px for large); radius 5px. One primary button per view; pair with a text/tertiary “Cancel”.
