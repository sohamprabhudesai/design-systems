neeto-molecules Catalog

Higher-level, product-ready patterns built on top of neetoUI (private package @bigbinary/neeto-molecules). When designing a neeto product, prefer one of these before inventing a new pattern. Grouped by purpose:

Layout & navigation

App structure

  • Sidebar — 64px icon rail with product switcher & profile
  • Header / SubHeader — page title bar + filter row
  • Container / Scrollable / TableWrapper — content scaffolding
  • MenuBar — secondary left menu for settings sections
  • NavigationHeader — tabbed page navigation
  • Breadcrumbs — gray-600 trail with “/” separators
  • ConfigurePageSidebar — settings navigation column

Views

  • BoardView — kanban columns with drag targets
  • CalendarView — month/week scheduling grid
  • DndTable — table with draggable rows
  • CardLayout / Columns — card grids and column splits
  • AuditLogs — timestamped activity feed
  • VersionHistory — diff list with restore
  • Insights — metric tiles + charts dashboard

Pages

  • LoginPage — centered 400px auth card
  • ErrorPage — 404/500 with illustration + CTA
  • PageLoader — full-page centered spinner
  • Onboarding — checklist/stepper first-run flow
  • Settings — sectioned settings page template

Input & editing

Editors

  • DocumentEditor — rich text editor (neeto-editor)
  • Codeblock — syntax-highlighted code with copy
  • InlineInput / Rename — click-to-edit titles
  • SuffixedInput — input with fixed domain suffix
  • OptionFields — repeatable option rows (choices)
  • DynamicVariables — {{variable}} inserter

Pickers

  • EmojiPicker / IconPicker — searchable grids
  • GoogleFontPicker — font preview list
  • DateRangeFilter — presets + custom range
  • PhoneNumber / Currency — formatted inputs
  • FileUpload — drop zone with previews
  • Search — global ⌘K search with results

Communication

  • EmailForm / SendToFields — To/Cc/Bcc composer
  • EmailPreview / BrowserPreview / MobilePreviewHeader — device previews
  • ShareViaEmail / ShareViaLink — share sheets
  • EmojiReactions — reaction pills
  • HelpPopover — “?” help bubble

Feedback & operations

Modals

  • ConfirmationModal — typed-confirmation destructive dialog
  • DeleteArchiveModal — delete vs archive choice
  • FinderModal — ⌘K style record finder
  • TimezoneMismatchModal — TZ conflict warning

Status & publishing

  • StatusDropdown — colored status switcher button
  • PublishBlock / PublishYourItem — publish CTA blocks
  • CopyToClipboardButton — copy with success flash
  • StickyRibbonsContainer — top announcement ribbons
  • SubscriptionNotificationsContainer — plan nudges
  • ToggleFeatureCard — feature card with Switch
  • IntegrationCard — logo + connect state card

Utilities

  • KeyboardShortcuts — Kbd cheatsheet pane
  • Metadata / DateFormat — consistent meta display
  • ImageWithFallback — avatar/logo fallbacks
  • IpRestriction / SessionEnvironment / BrowserSupport — security & env notices
  • MadeWith — “Made with neeto” badge
  • NeetoWidget — embedded helpdesk widget
Full inventory: ~80 components + 7 layout primitives. Storybook: neeto-molecules.neeto.com.
